# 挖矿辅助 · Mining Assistant（Fabric 26.2）

**制作者：wangguan123**

**这是 Baritone 的增强与优化层，不是替代品。** 它不打包、不修改 Baritone 本体，而是在 Baritone 之上加一层中文操作面板，按 **B** 打开就能选目标方块、圈选区、检查物资、开始挖掘，并管理自动吃食物、自动保护和紧急回家；同时针对部分服务器的实际情况补充了一批行为优化。

> 本项目包含对 Baritone 的适配与用法改进，**不包含 Baritone 源码**。自动挖掘能力来自 Baritone 本身，版权归其作者。

- 客户端模组，**服务器不用装**
- 适配 **Minecraft Java 26.2** / Fabric Loader **0.19.3+** / **Java 25**
- 自动挖掘依赖**同版本的 Baritone**（Fabric 版）；没装 Baritone 时面板仍可打开，但无法真正开挖

## 和 Baritone 是什么关系

- **Baritone 负责“挖和走”**：寻路、挖掘、执行任务，这些能力全部来自 Baritone。
- **本模组负责“怎么说、怎么管、边界怎么定”**：中文界面、目标方块选择、选区、开工前检查、物资核对、吃饭与自保、紧急回家。
- 两者是**叠加关系**：`Baritone` 装在 `mods` 里，本模组也装在 `mods` 里，缺一不可。没装 Baritone 时面板能打开，但任务不会真正执行。
- 本模组**不包含也不重新分发 Baritone 的代码**，只通过它的公开接口调用；Baritone 的版本兼容问题由 Baritone 负责。

## 相比直接用 Baritone，多了什么

原版 Baritone 靠命令和设置项工作，这里把它包装成一个能看懂、能检查的流程，主要做这几件事：

- **中文图形界面**：目标方块、选区、参数都用按钮和中文说明，不用背命令。
- **开工前检查**：先核对镐、垫方块、食物，再确认范围和风险，避免误点直接开挖。
- **分层清理**：按层往下推，本层没清完不会先拆下层（代码见 `LayeredClear`）。
- **自动进食**：饱食度下降时按你设定的优先级换手吃（`FoodSwap` / `FoodPreferences`）。
- **受击自保**：被怪打时切剑/斧反击，没有可用武器就停止采矿动作，而不是继续硬挖（`ProtectionController`）。
- **紧急回家**：危险时保存工作点并尝试 `/tp` 回城，回来后提示重新确认环境（`EmergencyController`）。
- **状态可回看**：任务暂停/受阻时说明原因，而不是默默不动。

## 下载与安装

1. 到本仓库右侧 **Releases** 下载最新的 `mining-assistant-<版本>.jar`。
2. 完全退出 Minecraft。
3. 把 jar 和匹配 26.2 的 Baritone Fabric 模组一起放进 `mods` 文件夹。
4. 启动游戏，进世界或服务器，按 **B** 打开面板。

> 只装本模组也能启动游戏；挖掘任务需要 Baritone 才会真正执行。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 挖矿 / 平地 | 选择最多两个目标方块（例如钻石矿 + 深层钻石矿），逐层清理 |
| 选区挖掘 | 持木棍点两个角或直接填坐标，限定施工范围 |
| 物资检查 | 开挖前核对镐、垫方块与食物 |
| 开始前检查 | 范围与风险确认，误点也不会立刻开工 |
| 自动进食 | 饱食度下降时按优先级换手吃，可配置 |
| 自动保护 | 受击时切剑/斧反击，无武器时停止采矿动作 |
| 紧急回家 | 危险时保存工作点并尝试 `/tp` 回城，回来后需重新确认环境 |

## 第一次使用

1. 先站在安全、平整、不会被怪物攻击的位置。
2. 按 B，选择「挖矿/平地」或「选区挖掘」。
3. 选择最多两个目标方块，例如钻石矿和深层钻石矿。
4. 需要范围时，手持木棍按界面提示点两个角，或直接填写坐标。
5. 打开「物资检查」，确认镐、方块和食物已经准备好。
6. 点「开始前检查」，确认范围和风险后，再点「开始」。

## 重要限制

- 复杂地形、浮空方块、狭窄空间、树叶和怪物干扰仍可能让任务暂停、绕路或超时。
- 它只是尽量让 Baritone 正常走路和挖掘，不是无敌机器人；**先在备份世界或实验服测试**。
- 自动进食和自动反击属于辅助功能，仍受背包、攻击冷却和服务器规则影响。
- 「紧急回家」需要服务器允许 `/tp`。没有 OP 或服主插件授权时，模组不能绕过服务器权限。
- 传送回家前会尝试保存工作位置；传送后必须停止任务，回到工作点后请先检查周围环境再继续。
- **部分服务器禁止自动挖掘类模组。** 使用前请确认你要玩的服务器规则，被封禁与作者无关。

## 从源码构建

需要 JDK 25。

```bash
./gradlew build
```

产物在 `build/libs/mining-assistant-<版本>.jar`。Windows 用 `gradlew.bat build`。

## 与「中文指令助手」的关系

这是独立的挖矿辅助模组（Baritone 的优化层），不包含指令搜索、指令收藏和中文指令教程。需要可视化学习服务器指令的，另装 `chinese-command-helper`（另一个仓库）。两个模组可以同时安装，也可以只装其中一个。
